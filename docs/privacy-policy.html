2. 개인정보의 이용 목적

  • 이용자 확인과 로그인 유지
  • 환경지킴이 모집 신청, 청소 구역 배정과 활동 관리
  • 청소 인증 사진의 검수(AI 자동 검수와 교사 확인)와 결과 안내
  • 이의신청 접수와 처리 결과 안내
  • 봉사(활동) 시간 산정과 기록 관리
  • 청소 시간 알림 제공(기기 안에서 예약하는 알림)

3. 개인정보 처리의 위탁 및 제3자 제공

AI 사진 검수(Google Gemini API). 청소 인증으로 제출한 사진은 자동 검수를 위해 Google의 Gemini API로 전송됩니다. 서버 코드에서 확인되는 전송 내용은 다음과 같습니다.

  • 전송: 인증 사진 파일, 청소 구역 이름과 설명, 검수 지시문
  • 전송하지 않음: 이름, 학번, 이메일 등 이용자 식별 정보(요청 본문에 포함하지 않음)
  • 사람은 평가하지 않도록 지시하지만, 사진에 사람이 찍힐 수는 있습니다. 사람이 찍힌 사진의 처리 안내: [확인 필요]

Google이 전송받은 사진을 보관하는 기간, 모델 학습에 쓰는지 여부, 처리 국가는 사용 중인 Gemini API 요금제와 약관에 따르며 코드로는 확인되지 않습니다. [확인 필요]

AI가 통과로 판단한 경우만 자동 승인되며, 그 밖의 경우(미통과, 오류, 대기 초과 등)는 교사 확인으로 넘어갑니다.

인증 방식(dataGSM). 로그인은 dataGSM OAuth로 이루어지며 비밀번호는 앱과 서버에 전달되지 않습니다. dataGSM에서 받는 항목은 위 1항과 같습니다.

서버 호스팅·저장소 업체: [확인 필요: 위탁 업체명, 위탁 업무, 서버 위치]

위 경우 외에 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 법령에 근거한 요청이 있는 경우는 예외입니다. [확인 필요]

4. 보관 기간 및 파기

  • 회원 탈퇴 시. 이름은 "탈퇴한 사용자"로, 이메일은 식별할 수 없는 임의 값으로 바뀌고, 학번·학년·반은 삭제되며, dataGSM 계정 식별자는 실제 계정과 연결되지 않는 값으로 바뀝니다. 모든 로그인 토큰이 무효화되고, 청소 구역 배정과 모집 신청 내용은 삭제됩니다.
  • 탈퇴 후에도 남는 기록. 청소 인증, 이의신청, 봉사 시간 기록은 학교 기록이므로 익명화된 상태로 남습니다. 이 기록에 연결된 사진 파일을 탈퇴 시 삭제하는 로직은 서버 코드에서 확인되지 않습니다. [확인 필요: 사진 파일 처리 방침]
  • 사진 보관 기간. 서버 코드에는 사진을 일정 기간 뒤 자동 삭제하는 기능이 없습니다(제출 도중 실패한 경우에만 삭제). 보관 기간: [확인 필요]
  • 인증·이의신청·봉사 시간 기록 보관 기간: [확인 필요]
  • 파기 방법. 데이터베이스 기록과 서버에 저장된 사진 파일의 파기 절차: [확인 필요]

앱 안에서 탈퇴를 요청하는 화면은 현재 확인되지 않습니다(서버에는 탈퇴 기능이 있음). 탈퇴 요청 방법: [확인 필요]

6. 기기에 저장되는 정보와 권한

  • 로그인 토큰: 기기의 Keychain에 저장하며, 이 기기에서만 접근할 수 있는 설정입니다. 로그아웃하거나 세션이 만료되면 지웁니다.
  • 사용자 요약: 이름, 학번, 학년, 반, 사용자 번호를 앱 저장소(UserDefaults)에 저장하고 로그아웃할 때 지웁니다.
  • 설정: 청소 알림 사용 여부와 알림 예약에 쓰는 구역 이름·시각, 닫은 공지 목록을 기기에 저장합니다.
  • 카메라: 청소 인증과 이의신청 사진을 촬영하는 데만 사용합니다. 갤러리 사진은 쓰지 않습니다.
  • 알림: 청소 시간 알림은 기기 안에서 예약하며, 허용하지 않아도 앱을 쓸 수 있습니다.
